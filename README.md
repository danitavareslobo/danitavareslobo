## Oi! Eu sou a Dani Tavares Lobo 👋

<br>

Sou desenvolvedora full-stack, apaixonada por criar soluções que funcionam bem do back-end à interface. Trabalho com **C#, ASP.NET Core e SQL Server** no back-end e com **React e TypeScript** no front-end, e também tenho experiência com **Blazor**.

No back-end, construo APIs RESTful com Entity Framework Core, CQRS, autenticação com JWT e Identity, Swagger, Hangfire e Redis. No front-end, desenvolvo interfaces responsivas e acessíveis com Tailwind CSS, React Hook Form + Zod, TanStack Query e Zustand. No dia a dia, uso Git/GitHub, Docker, testes automatizados (xUnit e Vitest) e metodologias ágeis como o Scrum.

Estou comprometida em enfrentar desafios técnicos, aprender continuamente e contribuir para o sucesso da equipe.
